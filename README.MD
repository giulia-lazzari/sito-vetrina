# Durlindana – Sito Web Turistico

Sito web vetrina per un’attività di noleggio barche ed esperienze in mare a Castro Marina (LE).  
Il progetto è pensato per presentare servizi turistici in modo chiaro.


## Obiettivo del progetto

L’obiettivo principale del sito è:

- Presentare servizi nautici e turistici
- Comunicare fiducia e professionalità
- Offrire un’esperienza di navigazione semplice e intuitiva

## Live Demo

https://giulia-lazzari.github.io/sito-vetrina/

## Struttura del sito

Il sito è composto da 4 pagine principali:

- **Home**
  - Hero video immersivo
  - Sezione servizi in evidenza
  - Mappa posizione

- **Chi siamo**
  - Storytelling dell’attività
  - Storia di Rocco e Cristiana
  - Immagini e identità del brand

- **Servizi**
  - Noleggio barche
  - Tour guidati
  - Barca a vela
  - Canoe e pedalò
  - CTA per prenotazione

- **Contatti**
  - Form di richiesta informazioni/prenotazione
  - Contatti diretti
  - Informazioni aziendali


## Tecnologie utilizzate

- HTML5
- CSS3 (layout responsive con Grid e Flexbox)
- JavaScript
- Google Fonts (Roboto)


## Caratteristiche UI/UX

- Design responsive mobile-first
- Hero a schermo intero con overlay
- Card interattive con hover (zoom + shadow)
- Menu mobile con hamburger toggle
- Footer ottimizzato per conversione

## Responsive Design

Il sito è completamente responsive e ottimizzato per:

- Smartphone
- Tablet
- Desktop


## Funzionalità JavaScript

- Toggle menu mobile
- Navigazione fluida tra sezioni
